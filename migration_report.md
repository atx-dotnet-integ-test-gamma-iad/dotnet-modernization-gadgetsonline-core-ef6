**Root Cause:** The DMS migration project's metadata model could not find the schema objects in the source database, likely because the database schema has already been migrated or the source server is no longer accessible.

## Manual Conversion Rules Applied

Since DMS failed for all statements, manual conversion was performed with these rules:
1. Schema mapping: `[dbo]` → `gadgetsonline_dbo`
2. All table and column names converted to lowercase
3. SQL Server `TOP(@count)` → PostgreSQL `LIMIT @count`
4. SQL Server `TOP(1)` → PostgreSQL `LIMIT 1`
5. SQL Server `CAST AS DECIMAL(18,2)` → PostgreSQL `CAST AS NUMERIC(18,2)`
6. Square bracket notation removed (PostgreSQL uses unquoted identifiers)
