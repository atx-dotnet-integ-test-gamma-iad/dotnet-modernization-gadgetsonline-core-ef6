GadgetsOnline - Microsoft SQL Server to PostgreSQL Migration
================================================================================

1. EXECUTIVE SUMMARY
================================================================================
The GadgetsOnline ASP.NET Core web application has been migrated from Microsoft
SQL Server to PostgreSQL. The application uses Entity Framework 6 (EF6) for
database access exclusively - no raw inline SQL statements exist in the codebase.

All database access is performed through EF6 LINQ operations, which have been
mapped to their SQL Server and PostgreSQL equivalents for analysis and validation.
The migration involved:
  - Replacing SQL Server packages (Microsoft.Data.SqlClient) with Npgsql
  - Configuring EF6 for PostgreSQL using EntityFramework6.Npgsql
  - Mapping all entity models to PostgreSQL schema (gadgetsonline_dbo) with
    lowercase table/column names
  - Updating connection strings from SQL Server to PostgreSQL format
  - Implementing DateTime UTC handling for PostgreSQL compatibility
